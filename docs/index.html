Worum geht es?

Diese Seite analysiert alle publizierten Versionen der FHIR-Profile des MII Kerndatensatzes (2019–2026) und zeigt, welche Versionen strukturell kompatibel sind — also ab wann sich Daten von Standorten direkt aggregieren lassen.

Die zentrale Metapher: Wie ein U-Bahn-Netz. Jede Linie ist ein Profil, jede Station ein Release. Wo die Linie durchgängig ist, sind die Versionen aggregierbar. Umsteigepunkte markieren Breaking Changes.

Legende und Hinweise

Farben der Stationsverbindungen

  • identical — Differential exakt gleich
  • canonical-only — nur Versions-/URL-Bump
  • elements-added — neue Elemente, additive
  • elements-removed — entfernte Elemente
  • modified — Element-Eigenschaften geändert
  • mixed — gemischt, meist Major-Bump
  • renamed — Canonical-Umbenennung, inhaltsgleich (eine Lane)
  • governance-migration — nach ISiK 6 übergegangen (nur URL-Zuordnung, keine Konformitätsaussage)

Symbole

  • Station = publiziertes Release
  • ✕Umsteigebahnhof = Breaking Change
  • Größere Station = mehr Profile in dieser Version
  • Linien-Farbverlauf = Kategorie der Transition

Navigation

  3. Auf eine Station oder ein Segment klicken → Detail rechts
